# CC0 bilateral hand source

`Hands + armature.blend` is a permitted local copy of the CC0 source used by
the guitar hand authoring script. The matching original license is preserved
in `92895 - LICENSE.html`.

Authoring entry point:

```text
scripts/author-chord-hand-assets.py
```

Open the blend in Blender's GUI and execute that script from the Blender
Python console. The script writes the optimized runtime GLBs under
`public/models/guitar-technique/` and never saves this source blend.
